# Catálogo Web Interactivo - App Películas

Aplicación web desarrollada con JavaScript vanilla orientada al consumo de una API REST externa para la exploración y visualización dinámica de un catálogo multimedia.

## Tecnologías y Herramientas Utilizadas
* **JavaScript (ES6+)**: Consumo de servicios asíncronos (`fetch`), manipulación del DOM y renderizado dinámico.
* **HTML5**: Estructuración semántica de componentes de interfaz.
* **CSS3**: Estilos visuales modernos, diseño responsivo y distribución de elementos.
* **Git & GitHub**: Control de versiones y despliegue del código fuente.

---

## Características Principales
* **Visualización Dinámica**: Muestra pósters, títulos y metadatos detallados de películas obtenidos en tiempo real desde la API.
* **Interfaz Responsiva**: Diseñada para adaptarse de manera fluida a diferentes tamaños de pantalla (dispositivos móviles y escritorio).
* **Consumo de API REST**: Implementación de peticiones HTTP asíncronas para el manejo eficiente de datos.

1. Clona este repositorio en tu computadora:
2. ```bash
